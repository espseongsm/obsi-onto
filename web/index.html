볼트 설정

노트가 있는 곳

Finder에서 로컬 또는 iCloud Drive 폴더를 선택하거나 경로를 직접 입력하세요.

iCloud 볼트는 Finder에서 ‘다운로드 유지’를 권장합니다. 이 앱은 동기화 완료 여부를 판단하지 않습니다.

경로·제외 규칙·날짜 해석 설정이 바뀌면 색인 후 예상 질문을 다시 만듭니다. 질문 생성에 사용하는 노트 범위는 ‘모델과 데이터’에서 확인하세요.

모델과 데이터

처음 한 번 공개 모델 파일을 다운로드합니다. 로컬 모델은 노트와 질문을 외부로 전송하지 않습니다.

생성 모델은 선택 사항입니다

설정하지 않아도 원문 근거를 찾을 수 있습니다. 생성 모델과 외부 임베딩은 각각 환경변수로 설정합니다. 자세한 내용은 README를 확인하세요.

로컬 색인 삭제

검색 색인·질문 기록·검토 결과를 삭제하고 볼트 연결을 해제합니다. 원본 노트와 공개 모델 파일은 보존합니다.

자동 갱신

OS 변경 알림을 우선 사용합니다. 보완 대조는 본문을 읽지 않으며 질문·색인 작업 중에는 연기합니다.
