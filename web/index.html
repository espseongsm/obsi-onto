Open the Obsi Onto local app

This app runs on a local server. Opening the HTML file directly will not enable search or graphs.

Run this command in a terminal from the project folder.

uv run main.py

Open local app → http://127.0.0.1:8765/

If the server is already running, open the link above. Use the corresponding address if you chose another port.

If this notice remains visible at the server address, refresh the page and check that JavaScript is enabled.

LOCAL FIRST

Vault settings

Your notes folder

Choose a local or iCloud Drive folder in Finder, or enter its path.

For iCloud vaults, choose “Keep Downloaded” in Finder. This app does not verify whether cloud sync has finished.

Changing the path, exclusions, or date settings regenerates suggested questions after indexing. See “Models & data” for the notes used to generate questions.

Models & data

Downloads the public model files once. The local model keeps your notes and questions on your computer.

A generation model is optional

You can find source evidence without one. Configure generation and external embeddings separately with environment variables. See the README for details.

Delete local index

Deletes the search index, chat history, and review results, then disconnects the vault. Your original notes and downloaded model files are preserved.

Automatic updates

Uses file-system notifications first. Reconciliation checks metadata without reading note content and waits while queries or indexing are running.
