## 검증

- Python **76개** 전체 통과; 변경한 오버레이 중복 방지 회귀도 재확인했다.
- 그래프 JavaScript **5개**, Ruff 검사·서식과 JavaScript 구문 검사 통과.
- 추가 테스트는 느린 모델 중 색인/취소/전체 삭제/제외/원문 수정, 사용자 대기 후 원문 변경, 재시작/이벤트 재전송/중복 확인/트랜잭션 rollback, 벡터 복구를 포함한다.
- 이전 SPARQL과 이웃 조회 결과, SQL 이전/이후 문단 필터 의미, 모델 충돌 후보와 사용자 맥락 전달, 예상 질문의 늦은 응답 차단을 검증했다.
- 브라우저는 임시 가상 노트 2개로 충돌 대기·새로고침 복구·B 선택·답변 완료·과거 이력의 확인 보존을 검사했다. 외부 모델/실제 사용자 볼트는 사용하지 않았다.
- macOS 파일 감시 테스트는 FSEvents 접근이 허용된 환경에서 실행했다. 샌드박스의 감시 차단과 의존성 폐기 예정 경고는 제품 실패와 구분했다.

## 성능과 남은 비용

합성 1,000개 노트(4,000문단), FakeEmbedder, 모델·네트워크·감시 제외, 3회 중앙값: hybrid 검색 **131.3→39.9ms**, LLM 제외 답변 **165.2→79.2ms**. 변경 없는 대조는 본문/임베딩 0회다. [원시 이후 결과](benchmarks/refactor-after.json) · [이전 결과와 측정 조건](refactoring-review.md)

전체 RDF/SHACL은 약 743→721ms, 현재 볼트 그래프는 약 74ms로 남는다. 초기 색인 1회는 2.13→2.72초로 증가했고 원인을 분리 측정하지 않았다. 실제 볼트 지연/메모리/검색 품질 개선이나 Rust 대비 배속으로 해석하지 않는다.

## 보안 반영 범위

기존 저장 상태의 독립 보안 검토에서 중간 2건·낮음 2건을 확인했다. 다음은 현재 작업 파일의 수정 상태다. 원본 검토 산출물은 당시 스냅샷의 기록으로 유지한다.

| 검토 항목 | 수정 및 회귀 확인 |
|---|---|
| YAML alias 과도 확장 | SafeLoader subclass에서 alias 차단, byte/depth/node 상한 |
| 닫히지 않은 링크의 정규식 반복 | 후보 내부 중첩 시작 문자 제외, 링크/줄 길이 제한 |
| FIFO `.md`의 blocking read | 스캔/읽기 시 regular-file 확인, O_NONBLOCK open 후 fstat |
| 조상 디렉터리 symlink 교체 | vault descriptor에서 O_DIRECTORY/O_NOFOLLOW로 각 경로 열기 |

추가로 API 변경 요청 64KiB, GET 세션 토큰, 정확한 origin 검사, 모델 스키마/내용 한도와 새 DB/잠금 0600을 적용했다. 의존성 전체/바이너리 감사·공개 서버 운영 검증은 포함하지 않는다. 모델 의미적 안전성을 인용 ID 검사만으로 보장하지 않는다.

보안 도구가 반환한 사용량은 **5,601,956 tokens**다(input 5,562,884; output 39,072; cached input 5,215,232; reasoning 6,281은 output 일부). 4개 대화의 rollout 집계이며 긴 이전 대화·캐시를 포함하므로 이번 보안 검사만의 순수 추가 비용으로 해석하지 않는다.

## 운영 적용 및 후속 범위

실행 중인 서버를 종료하고 `uv run main.py`로 다시 실행하면 DB 열/작업 테이블을 추가한다. 실제 사용자 데이터로 서버를 재시작하거나 외부 API 품질 평가를 이번 검증에서 수행하지 않았다.

Python과 현재 저장 엔진을 유지했다. Rust/Agent SDK는 도입하지 않았다. 전체 RDF의 증분 검증, 현재 그래프 전체 투영·상태 API 목록 최적화, 확인의 재사용/개별 취소, 반대 주장 전용 추가 검색, 실제 모델 충돌 정밀도·재현율은 남은 범위다.
